# iTech Account COA Creator

## Description
This module adds a security group that allows users to create and edit accounts in the Chart of Accounts (COA) without requiring full accounting manager access.

## Features
- New security group: **COA Creator**
- Users in this group can create, read, write, and delete accounts
- Integrates seamlessly with Odoo 19 Enterprise Accounting module

## Installation
1. Copy the module to your Odoo addons directory
2. Update the apps list
3. Install the module

## Usage
1. Go to **Settings > Users & Companies > Groups**
2. Find the **COA Creator** group
3. Assign users to this group who need to create accounts in the Chart of Accounts
