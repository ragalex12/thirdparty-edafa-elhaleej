# OpenProject Tools

This folder contains the workspace-level helper shell scripts used to organize, clean, and initialize the OpenProject workspace.

Contents:
- organize_workspace.sh: organize loose root helper files into the dedicated folders
- cleanup_temp_files.sh: remove temporary files from /tmp
- setup_workspace.sh: run organization, cleanup, and alias setup in one step
- openproject_aliases.sh: shell aliases for fast OpenProject access

The main launcher remains in the workspace root:
- /opt/localaddons/open_openproject.sh
